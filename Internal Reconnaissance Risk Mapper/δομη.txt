5. irmapper.py

Αυτό είναι το αρχείο που θα τρέχει ο χρήστης.

Παράδειγμα:

python irmapper.py --target 192.168.1.0/24

Δεν θα περιέχει όλη τη λογική.

Θα κάνει μόνο αυτό:

from irmapper_core.cli import main

if __name__ == "__main__":
    main()

Δηλαδή θα καλεί το main() από το module cli.py.

9. irmapper_core/cli.py

Αυτό είναι το command-line interface.

Είναι υπεύθυνο για:

- Να διαβάζει arguments από τον χρήστη
- Να καλεί τον target parser
- Να φορτώνει config files
- Να ξεκινά το scanning
- Να καλεί το risk engine
- Να καλεί τον reporter

Παράδειγμα arguments:

python irmapper.py --target 192.168.1.0/24 --output reports/report.json

Μελλοντικά:

python irmapper.py \
  --target 192.168.1.0/24 \
  --ports config/default_ports.yml \
  --format html \
  --threads 50

Το cli.py δεν θα κάνει scanning μόνο του. Θα συντονίζει τα υπόλοιπα modules.

10. irmapper_core/target_parser.py

Αυτό αναλαμβάνει να μετατρέπει το target σε λίστα από IPs.

Θα δέχεται:

192.168.1.10
192.168.1.0/24

και θα επιστρέφει:

["192.168.1.1", "192.168.1.2", "192.168.1.3", ...]

Ευθύνη του:

- Έλεγχος αν το target είναι σωστό
- Υποστήριξη single IP
- Υποστήριξη CIDR
- Απόρριψη invalid input
11. irmapper_core/scanner.py

Αυτό είναι το module που κάνει το port scanning.

Ευθύνη του:

- Να παίρνει λίστα από hosts
- Να παίρνει λίστα από ports
- Να ελέγχει ποια ports είναι ανοιχτά
- Να επιστρέφει raw scan results

Παράδειγμα output:

{
    "host": "192.168.1.10",
    "open_ports": [
        {
            "port": 22,
            "service": "SSH"
        },
        {
            "port": 445,
            "service": "SMB"
        }
    ]
}

Σημαντικό:
Το scanner.py δεν πρέπει να αποφασίζει αν κάτι είναι High ή Medium risk. Αυτό θα το κάνει το risk_engine.py.

12. irmapper_core/banner_grabber.py

Αυτό προσπαθεί να πάρει βασικές πληροφορίες από κάποιες υπηρεσίες.

Για παράδειγμα:

SSH banner
HTTP headers
HTTPS headers

Παράδειγμα:

OpenSSH_8.9
Apache/2.4.58
nginx/1.24

Ευθύνη του:

- Να κάνει ασφαλές, ελάχιστο banner grabbing
- Να μην κάνει authentication
- Να μην κάνει brute force
- Να μην εκτελεί exploits

Θα χρησιμοποιείται κυρίως για:

- SSH
- HTTP
- HTTPS
- HTTP-Alt
- HTTPS-Alt
13. irmapper_core/service_classifier.py

Αυτό παίρνει τα open ports και τα μετατρέπει σε πιο κατανοητές κατηγορίες.

Παράδειγμα:

port 445 -> file_sharing
port 3389 -> remote_access
port 3306 -> database
port 8080 -> possible_admin_interface

Ευθύνη του:

- Κατηγοριοποίηση υπηρεσιών
- Εντοπισμός πιθανών admin interfaces
- Εντοπισμός sensitive services

Παράδειγμα output:

{
    "service": "SMB",
    "category": "file_sharing",
    "exposure_type": "internal_lateral_movement_risk"
}
14. irmapper_core/risk_engine.py

Αυτό είναι από τα πιο σημαντικά modules.

Παίρνει τα αποτελέσματα από το scanner και υπολογίζει:

- risk score
- severity
- findings
- recommendations

Παράδειγμα:

{
    "score": 75,
    "level": "High",
    "findings": [
        {
            "title": "SMB exposure",
            "severity": "High",
            "description": "SMB is reachable from the internal network.",
            "recommendation": "Restrict SMB access and audit shared folders."
        }
    ]
}

Λογική:

SMB open         +25
NFS open         +25
RDP open         +20
Database open    +15
Admin panel      +15
SSH open         +10
HTTP open        +5

Μετά:

0–30    Low
31–69   Medium
70–100  High

16. irmapper_core/models.py

Εδώ θα ορίσουμε τα βασικά data models.

Για αρχή μπορούμε να χρησιμοποιήσουμε Python dataclasses.

Παράδειγμα:

from dataclasses import dataclass
from typing import Optional


@dataclass
class ServiceResult:
    port: int
    service: str
    category: str
    banner: Optional[str] = None


@dataclass
class Finding:
    title: str
    severity: str
    description: str
    recommendation: str


@dataclass
class HostResult:
    host: str
    services: list[ServiceResult]
    findings: list[Finding]
    risk_score: int
    risk_level: str

Γιατί το θέλουμε;

Για να μη μεταφέρουμε απλά dictionaries παντού χωρίς δομή.

Ροή λειτουργίας του εργαλείου

Η λογική ροή είναι αυτή:

1. Ο χρήστης δίνει target
        │
        ▼
2. cli.py διαβάζει τα arguments
        │
        ▼
3. target_parser.py μετατρέπει target σε λίστα IPs
        │
        ▼
4. cli.py φορτώνει ports και risk rules από config/
        │
        ▼
5. scanner.py ελέγχει hosts και ports
        │
        ▼
6. banner_grabber.py παίρνει banners όπου γίνεται με ασφάλεια
        │
        ▼
7. service_classifier.py κατηγοριοποιεί τις υπηρεσίες
        │
        ▼
8. risk_engine.py υπολογίζει findings και risk score
        │
        ▼
9. reporter.py δημιουργεί terminal / JSON / HTML report
